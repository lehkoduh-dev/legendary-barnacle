# Beach Heaven: сайт, факты и решения (2026-10-10)

## Продукт (из файлов проекта)
- 3 SKU, все 37,5% vol., 70 cl. Производитель на этикетках: Kroonbrau BV, Amsterdam.
- Pink Dream (EAN 8720892516206): сахар 35,6 г/л (на сайте НЕ указываем). Ароматы в составе: грейпфрут, гибискус, черника.
- Lychee Bliss (EAN 8720892516220): сахар 17,8 г/л. Личи, лимон, лайм, огурец, имбирь.
- Spiced Velvet (EAN 8720892516213): сахар 26,7 г/л. Апельсин, лайм (+ вермут, карамельный краситель E150a).
- Таблица состава (xlsx) говорит 40%, этикетки и решение Павла: 37,5%.

## Ограничения по текстам (письмо ODB Beverages 09.06.2026 + переписка 22-25.05)
- На этикетках есть то, чего нет в жидкости: грейпфрут и ваниль (Lychee), корица, тостированный дуб, шоколад (Spiced), розы (Pink). Не использовать в текстах.
- По ODB: ваниля и корицы в Spiced Velvet нет.
- ЕС: слово «rum» отдельно нельзя, категория должна быть вроде «Spirit Drink». На сайте: «Rum-based tropical spirit drink». Этикетки не менялись (продажа вне ЕС, решение Kroonbrau).
- «Caribbean» не использовать (в составе не карибский ром).

## Сайт beachheavenrum.com
- Статика, только английский, VPS 5.188.23.96 (FastPanel), Cloudflare DNS (A-записи на VPS, Proxied).
- Страницы: главная, 3 SKU, wholesale (форма через mailto). Возрастной экран с датой рождения (18+), без cookies и аналитики.
- Контактный email на сайте info@beachheavenrum.com: подтвердить.
- Фото: пока иллюстрации бутылок из арта этикеток; заменить на студийные (WOWCONTLY, ром ожидается ~23.10).
- Не использовать фото IMG_5591-5594 (прототип рядом с бутылкой Hooft).

## Решения 10.10.2026 (вечер)
- Сахар (г/л) на сайт не выводим нигде.
- Разделы сайта: Our Rums, Cocktails (12 рецептов, фильтры Blend/Level/Flavour), Experiences (3 статьи), Contact, Wholesale. Структура по аналогии с bacardi.com (возрастной экран с датой рождения, листинг коктейлей, статьи).
- Рецепты и статьи написаны нами как идеи подачи, без заявлений о продукте сверх подтверждённых фактов.
- Деплой: zip заливается в корень сайта FastPanel, пользователь scp/ssh с Mac; в Cloudflare после изменений css/js используется ?v=N для сброса кеша.
